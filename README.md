# HAFS Focus — Study OS

외대부고 학생을 위한 **비공식** 로컬 우선 공부 타이머·학교 일과·시간표 웹앱. 기존 RESET LAB 3.0의 모노톤 사이드바·대시보드 스타일을 참고했으며, 개인용 Notion 연동·로그인·비밀번호는 포함하지 않습니다.

## 현재 기능 (v0.2)

- 첫 실행 **1/2/3학년 + 자연과학·인문사회·국제과정** 선택 (총 9가지 프로필 조합).
- **SETTINGS**에서 선택 변경. 계열·학년별 개인 주간 시간표(월~금 1~8교시)를 *분리 저장*하고 변경해도 이전 입력을 유지.
- [HAFS 공식 GMC 일과표](https://hafs.hs.kr/?act=doc&mcode=1516)에 근거한 1·2·3학년별 기상·조/중/석식·수업·ET·자습·주말 일과 기본값.
- 계열별 과목 편성은 **검증된 공개 데이터가 없어 빈 편집형 시간표**로 제공. 임의의 과목을 꾸며 넣지 않음.
- 과목별 타이머(시작·일시정지·재개·종료), 공부 유형, 과목별 집계·7일 통계, 할 일 및 마감일.
- 브라우저 localStorage 저장, JSON 내보내기/불러오기, 이전 로컬 프로토타입 데이터의 기본 이관.
- PWA: 매니페스트, 홈 화면 앱 설치 지원, 서비스 워커를 통한 앱 셸 오프라인 캐시. GitHub Pages 배포가 가능한 정적 HTML/CSS/JavaScript.

## 실행

`index.html`을 직접 열면 대시보드 기능을 확인할 수 있습니다. PWA 설치·서비스 워커는 **HTTPS 또는 localhost** 서버에서 작동합니다.

```bash
python -m http.server 8000
# http://localhost:8000
```

테스트: `node --test tests/*.test.cjs` (Node.js 20 이상 권장).

## GitHub Pages

Repository Settings → Pages → Build and deployment → **Deploy from a branch** → `main` / `(root)` → Save.

배포되면 `https://ggy5555.github.io/hafs-focus/`로 접속할 수 있습니다. Pages 활성화 이전에는 해당 URL이 동작하지 않을 수 있습니다.

## 데이터·개인정보

계정 없음, 서버 동기화 없음, 실제 랭킹·그룹 기능 없음. 공부 기록은 사용 중인 **해당 브라우저**에만 보관되며 삭제 시 복구하려면 JSON 백업이 필요합니다. PC·휴대폰 간 기록 자동 동기화는 아직 불가능합니다. 공개 저장소에 학생 개인정보·비밀번호·토큰을 넣지 마세요.

## 검증과 남은 작업

- 검증된 기본 일과는 HAFS GMC 공식 페이지에 있는 내용에 한정합니다. 시험, 학사일정, ET 개인선택 등은 반영되지 않습니다.
- 실제 계열별 정규 수업 시간표는 사용자나 학교 자료가 확보되면 **개인 설정 및 검증된 프리셋**으로 확장할 수 있습니다.
- 여러 기기 브라우저 동작, 홈화면 설치, 접근성, 실제 학교 사용성 테스트는 추가로 진행해야 합니다.

상세 출처와 구현 결정은 [`docs/schedule-sources.md`](docs/schedule-sources.md)를 참조하세요.
